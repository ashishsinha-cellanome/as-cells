# Spec: Dynamic Color-Blind Friendly Generalization Tracker Plots

## Overview
Currently, the generalization performance tracking plots generated by `track_generalization.py` use a static 8-color Okabe-Ito color-blind friendly palette (`OKABE_ITO`). 
When the number of tracked experiments exceeds 8, the color assignment wraps around and starts repeating. For example, in the current tracking dataset containing 10 experiments (1 baseline and 9 active experiments), `2 Nodes` and `7 Nodes (hs675+astro))` both map to `#56B4E9` (Sky Blue), causing visual ambiguity in the plots.

The system will implement a dynamic, highly distinct, infinite-scaling, color-blind friendly color generation scheme based on the golden ratio conjugate in HSL space. 

## Scope
### In Scope
- Define and implement a dynamic color-blind friendly palette generator using a golden ratio conjugate HSL calculation.
- Integrate the dynamically generated palette into `track_generalization.py` for rendering:
  - Matplotlib Scatter Plot (`generalization_relative_performance_scatter.png`)
  - Matplotlib Scatter + Lines Plot (`generalization_relative_performance_lines.png`)
  - Plotly Interactive Plot (`generalization_relative_performance.html`)
- Support scaling gracefully to any arbitrary number of experiments ($N$).

### Out of Scope
- Altering the baseline color (it will remain a distinct neutral gray/fixed color).
- Modifying underlying model metrics, data schema, or evaluation procedures.
- Implementing UI toggles or dynamic user customization options for the colors.
- Altering palettes or plotting scripts of other modules outside of `track_generalization.py`.

## Architecture Overview
The plotting module in `track_generalization.py` will transition from a fixed list of colors to a dynamic generation algorithm. 

The core mathematical principle uses the **golden ratio conjugate** $\phi^{-1} \approx 0.618033988749895$ to spread hues uniformly across the 360-degree color wheel. This ensures that regardless of the number of experiments ($N$), every single series gets a hue that is mathematically placed as far as possible from all existing hues.

To guarantee safety under all forms of color blindness (such as deuteranopia, protanopia, and tritanopia), the algorithm will also **alternate lightness (luminance) and vary saturation** of consecutive colors. This guarantees high contrast in brightness and saturation, enabling visual distinction even if two hues look similar or identical to color-blind observers.

## Components & Responsibilities

### 1. Color Generation Algorithm (`generate_dynamic_colors`)
A new helper function `generate_dynamic_colors(n)` will be added to `track_generalization.py`.

- **Input:** $N$ (integer) — number of distinct colors required.
- **Output:** List of $N$ hex color strings.
- **Behavior:** 
  The algorithm will iterate index $i$ from $0$ to $N-1$:
  - Hue $h = (i \times \phi^{-1}) \pmod{1}$.
  - Lightness $l$ alternates between a darker shade ($0.45$) and a lighter shade ($0.70$).
  - Saturation $s$ varies across three values ($0.75$, $0.85$, $0.95$).
  - Convert HSL to RGB, and then to HEX format.

```python
import colorsys

def generate_dynamic_colors(n):
    colors = []
    inv_phi = 0.618033988749895  # Golden ratio conjugate
    
    for i in range(n):
        h = (i * inv_phi) % 1.0
        # Alternate lightness to ensure high luminance contrast between consecutive colors
        l = 0.45 + 0.25 * (i % 2)
        # Vary saturation slightly to provide further distinction
        s = 0.75 + 0.1 * (i % 3)
        
        r, g, b = colorsys.hls_to_rgb(h, l, s)
        hex_color = '#{:02x}{:02x}{:02x}'.format(int(r*255), int(g*255), int(b*255))
        colors.append(hex_color)
    return colors
```

### 2. Plot Generation Pipeline (`generate_plot`)
In `track_generalization.py`, `generate_plot` will be updated to:
- Dynamically fetch all unique non-baseline experiments and sort them alphabetically/numeral-wise:
  ```python
  non_baseline_exps = sorted([e for e in master_df['experiment'].unique() if e != baseline_name])
  ```
- Generate $N = \text{len}(non\_baseline\_exps)$ colors using `generate_dynamic_colors(N)`.
- Iterate through `non_baseline_exps` with `enumerate` to assign unique colors sequentially to:
  1. Matplotlib Scatter Plot (`generalization_relative_performance_scatter.png`)
  2. Matplotlib Scatter + Lines Plot (`generalization_relative_performance_lines.png`)
  3. Plotly Interactive Plot (`generalization_relative_performance.html`)

## Data Flow
1. **Load data:** Read `generalization_tracking.csv`.
2. **Filter & Sort:** Extract non-baseline experiments and sort them.
3. **Generate Palette:** Generate $N$ highly distinct colors.
4. **Render:** For each experiment, render dots/lines with the corresponding color.
5. **Save:** Save PNG and HTML files.

---

## Error Handling & Edge Cases
- **No experiments:** If $N = 0$, the generator gracefully returns an empty list, and the plotting function returns early.
- **Large $N$:** The algorithm handles any $N > 100$ without error, producing uniquely calculated colors for each experiment.
